 🔧 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
═════════════════════════════════════════════════════════════════════════════════

❌ Бот не запускается?
→ python -m bot.main
→ Проверьте BOT_TOKEN в config.py

❌ Mini App не открывается?
→ Обновите MINIAPP_URL в miniapp.py
→ Разверните web_app_mini.html на Vercel

❌ Database ошибка?
→ python -c "from database.models import *"
→ Проверьте DATABASE_URL в config.py

❌ Other issues?
→ Смотрите MINIAPP_GUIDE.md
→ Запустите debug_system.py
