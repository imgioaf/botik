⚠️ TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════════════

Problem: Bot won't start
  Solution 1: Check Python: python3 --version
  Solution 2: Test imports: python3 -c "from bot.main import *"
  Solution 3: Check .env: cat .env
  Solution 4: View errors: journalctl -u switzerbot -n 50 -p err

Problem: High memory usage
  Solution 1: Restart bot: systemctl restart switzerbot
  Solution 2: Monitor: top -p $(pgrep -f "python3 -m bot.main")
  Solution 3: Check for leaks: view logs for ERROR messages

Problem: Database locked
  Solution: Restart bot: systemctl restart switzerbot

Problem: Mini App not loading
  Solution 1: Check Vercel: curl https://your-miniapp.vercel.app
  Solution 2: Update MINIAPP_URL in bot configuration
  Solution 3: Check firewall: sudo ufw status
