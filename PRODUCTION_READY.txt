 ARCHITECTURE OVERVIEW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Technology Stack:
  - Language: Python 3.10+ with async/await
  - Framework: aiogram 3.x (Telegram bot framework)
  - Database: SQLAlchemy 2.0 async + SQLite (or PostgreSQL)
  - Blockchain: tonsdk (TON integration)
  - Crypto: tonsdk.crypto (key generation & signing)

Supported Currencies:
  - TON (native blockchain)
  - USDT (Jetton token on TON)
  - ETH (future integration)
  - BTC (future integration)

Financial Flow:
  1. User deposits → TONDepositMonitor detects (every 15 sec)
  2. Balance updates automatically (async polling)
  3. User transfers → transfer_internal() with FOR UPDATE lock
  4. Fee calculated: 0.5% of transfer amount
  5. Referral bonus auto-credited: 20% of fee to referrer
  6. User withdraws → on-chain transaction signed & broadcasted
  7. Failed withdrawal → automatic refund to balance

Database Schema (8 tables):
  - users (BigInteger PK, username, referrer_id self-FK)
  - wallets (user_id FK, currency, balance, deposit_address)
  - transactions (user_id FK, type, amount, fee, status)
  - checks (code, creator_id, amount, status)
  - invoices (creator_id, recipient_id, amount, status)
  - giveaways (creator_id, total_amount, winners_count, status)
  - subscriptions (owner_id, channel_id, price_month, status)
  - processed_transactions (idempotency table for deposits)
