 🎓 ИЗУЧЕННЫЕ УРОКИ
═════════════════════════════════════════════════════════════════════════════════

1. HTML в Telegram
   └─ Специальные символы нужно экранировать (&lt;, &gt;, &amp;)
   └─ parse_mode='HTML' требует правильный escape

2. Callback Data Parsing
   └─ Никогда не делать unsafe split() без валидации
   └─ Всегда проверять длину массива перед доступом
   └─ Использовать try-catch для преобразования типов

3. Message Editing
   └─ Проверять message.text перед edit_text()
   └─ Fallback на edit_caption() если нет текста
   └─ Использовать try-catch для Telegram API ошибок

4. SQL Aggregates
   └─ Aggregate функции (COUNT, SUM) нельзя использовать в WHERE
   └─ Использовать HAVING для фильтрации по aggregates
   └─ Для complex queries использовать subqueries

5. Async Operations
   └─ Всегда использовать await для async функций
   └─ SQLAlchemy нужна async session
   └─ aiosqlite для async SQLite операций
