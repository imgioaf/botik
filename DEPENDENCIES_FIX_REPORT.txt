ШАГ 2: Временное отключение TON монитора
─────────────────────────────────────────
Файл: bot/main.py

Было:
  from blockchain.ton_monitor import TONDepositMonitor
  ...
  monitor = TONDepositMonitor(...)
  asyncio.create_task(monitor.run())

Стало:
  # from blockchain.ton_monitor import TONDepositMonitor
  ...
  # monitor = TONDepositMonitor(...)
  # asyncio.create_task(monitor.run())

Причина: TON монитор требует tonsdk → bitarray → MSVC Build Tools
Решение: Оставлен комментарий на случай, если установить Build Tools позже

Если хотите включить TON монитор в будущем:

1. Установить Microsoft C++ Build Tools:
   https://visualstudio.microsoft.com/visual-cpp-build-tools/
   
2. Раскомментировать в bot/main.py:
   
   from blockchain.ton_monitor import TONDepositMonitor
   ...
   monitor = TONDepositMonitor(...)
   asyncio.create_task(monitor.run())

3. Установить tonsdk:
   pip install tonsdk==1.0.14

4. Перезапустить бота
