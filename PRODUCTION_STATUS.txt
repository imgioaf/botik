📞 DEPLOYMENT INSTRUCTIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. SSH into production server:
     ssh user@your-server-ip

  2. Clone or transfer bot code:
     git clone <repo> /opt/swiwallet
     cd /opt/swiwallet

  3. Setup Python environment:
     python3 -m venv venv
     source venv/bin/activate
     pip install -r requirements-core.txt

  4. Create .env configuration:
     cat > .env << 'EOF'
     BOT_TOKEN=<your-telegram-bot-token>
     DATABASE_URL=sqlite+aiosqlite:///switzerbot.db
     EOF

  5. Run pre-flight checks:
     bash production-debug.sh

  6. Choose deployment method:
     
     A) Long Polling (Simple):
        nohup python3 -m bot.main > bot.log 2>&1 &
     
     B) Systemd (Recommended):
        sudo bash deploy.sh
        sudo systemctl start switzerbot
     
     C) Manual startup:
        bash start-production.sh

  7. Deploy Mini App to Vercel:
     bash deploy-miniapp.sh

  8. Verify bot is running:
     curl https://api.telegram.org/bot<TOKEN>/getMe
     tail -f bot.log
