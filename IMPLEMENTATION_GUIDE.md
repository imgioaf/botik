FEATURE 2: CRYPTO SPLIT (Крипто-сплит)
───────────────────────────────────────

Шаги создания:
1. Нажать "💸 Сплит" → "➕ Создать"
2. Ввести: "50 TON" (сумма и валюта)
3. Ввести: "5" (количество людей)
4. Ввести: "Обед в ресторане" (описание)
5. Получить код вроде "ABC123D"

7. Отправить код друзьям

Шаги присоединения (для друга):
1. Получить код "ABC123D"
2. Нажать "💸 Сплит" → "🔍 Найти"
3. Ввести код
4. Увидеть "Ваша доля: 10 TON"
5. Нажать "💳 Оплатить"
6. Деньги переводятся создателю
7. Когда все оплатили → "✅ Все оплачено!"

Ожидаемый результат:
✅ Создается сплит с уникальным кодом
✅ Друзья могут присоединиться
✅ Видно кто оплатил, кто нет
✅ Все деньги переводятся создателю

Технические детали:
- SplitManager хранит сплиты в памяти
- ID сплита: 12 символов (hex)
- Статусы: active, completed
- Срок действия: 7 дней

FEATURE 4: ADVANCED SECURITY (Усиленная защита)
────────────────────────────────────────────────

2FA (Двухфакторная аутентификация):
1. Нажать ⚙️ Настройки → 🔐 Безопасность → 📱 2FA
2. Бот выдает QR код
3. Отсканировать QR в Google Authenticator
4. Ввести 6-значный код
5. Скопировать backup коды и сохранить
6. 2FA включена ✅

IP Whitelist:
1. ⚙️ Настройки → ⚪ IP Whitelist
2. Нажать "➕ Добавить IP"
3. Автоматически добавляется текущий IP
4. Если логин с другого IP → требуется код подтверждения
5. Можно управлять доверенными IP

Device Fingerprint:
1. Автоматический после включения 2FA
2. Каждое устройство получает unique ID
3. Новое устройство → требует коды 2FA
4. "Доверить на 30 дней" → не спрашивает снова

Ожидаемый результат:
✅ Аккаунт защищен от взлома
✅ Новые устройства требуют 2FA
✅ Новые IP требуют подтверждение
✅ Все операции залогированы
✅ Большие переводы требуют верификацию

Связанные файлы:
- bot/security_advanced.py (все функции)
- database/models.py (новые поля User)
